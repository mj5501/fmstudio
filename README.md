# 퍼메 스튜디오 v0.9.5

## v0.9.5 호출 문구 안내

- 새 프로젝트의 기본 호출 문구를 본문과 겹치기 어려운 `⪫⩊⪪`로 변경했습니다.
- 호출 문구가 정규식이 선택기 위치를 찾는 표식이라는 안내를 기본 설정에 추가했습니다.

## v0.9.4 빈 프로젝트로 시작

- 새 방문자와 `새 프로젝트`는 예시 관계·퍼메 없이 빈 이야기 구성으로 시작합니다.
- 브라우저에 자동 저장된 기존 프로젝트와 불러온 프로젝트는 그대로 유지됩니다.

## v0.9.3 새 퍼메 본문

- 새 퍼메의 본문은 빈 값으로 생성됩니다.
- `여기에 첫 메시지를 적어 주세요.`는 저장되지 않는 반투명 입력 안내로만 표시됩니다.

## v0.9.2 내보내기 정리

- 내보낼 내용 목록에는 첫 메시지와 Lua만 표시합니다.
- 표시 정규식 OUT은 내보내기 화면 아래의 접힌 참고 창에서 확인할 수 있습니다.

## v0.9.1 정규식 세트 저장

- 미리보기의 `관계를 먼저 선택해 주세요.`, `시작할 장면을 선택하세요.` 문구를 제거했습니다.
- 내보내기 탭에서 RisuAI가 바로 불러올 수 있는 `.regex.json` 정규식 세트를 저장할 수 있습니다.
- 세트에는 퍼메용 `editdisplay`, `editprocess` 항목만 포함됩니다.

## v0.9 관계 생략과 버튼 이미지 겹치기

- `디자인 → 문구 · 기능 → 관계 선택 단계 사용`을 끄면 모든 퍼메 버튼이 바로 나타납니다.
- 관계 단계가 꺼져도 왼쪽 관계 묶음은 퍼메 정리와 연결용으로 유지됩니다.
- 관계를 생략한 미리보기에서도 퍼메 버튼을 끌어 순서와 소속 묶음을 바꿀 수 있습니다.
- 관계·퍼메 버튼마다 글씨 위 이미지와 버튼 배경 이미지를 각각 지정할 수 있습니다.
- 두 이미지는 동시에 사용할 수 있고, 배경 초점과 어둡게 덮는 정도도 조절할 수 있습니다.

## v0.8 편집 화면과 초기 변수

- `정규식 JSON · 참고 / 도구용` 출력을 제거했습니다.
- 화면에 문자로 노출되던 `setdefaultvar` 초기 변수 코드와 `초기 변수 복붙용` 출력을 제거했습니다. 변수가 아직 없을 때 영어를 기본으로 처리하므로 초기화 코드를 붙일 필요가 없습니다.
- 상단 제목 영역을 작게 줄였습니다.
- 내용, 디자인, 이미지 설정을 접이식 묶음으로 나눴습니다. 디자인의 크기·PC/모바일 배치만 처음 열어 두며, 나머지는 필요한 부분만 펼칠 수 있습니다.
- 왼쪽 이야기 구성은 관계별로 퍼메 목록을 접거나 펼칠 수 있습니다. 접어도 관계와 포함된 퍼메 데이터는 그대로 유지됩니다.

## v0.7 프리셋과 이야기 구성 드래그

- 제공된 프리셋 화면에서 색을 추출해 Auto, Dark, Light, Midnight, Cream, Nord, Solarized, Rose, Mint, Sky, Lavender, Peach, Mocha, Slate, Dusk, Olive, Forest, Ocean, Wine 테마를 추가했습니다.
- 왼쪽 이야기 구성에서 관계와 퍼메 오른쪽의 `⠿` 부분 또는 행을 마우스로 끌어 순서를 바꿀 수 있습니다. 노란 선은 앞/뒤 삽입, 노란 점선은 해당 관계의 마지막으로 이동을 뜻합니다.
- 관계를 이동하면 아래 퍼메가 함께 이동합니다. 퍼메는 다른 관계로 옮길 수 있으며, 선택 상태와 본문 연결도 새 소속 관계에 맞춰 유지됩니다.

## v0.6 CBS와 상단 토글 수정

- 생성되는 표시 정규식과 첫 메시지에서 `{{:else}}`를 제거했습니다. 언어와 펼침 조건을 각각 `is`/`isnot` 블록으로 생성해 `:else`가 본문에 노출되는 문제를 막습니다.
- 접기/펼치기 버튼은 대괄호 없이 표시되며, 선택기 상단의 전체 가로 영역이 클릭되는 한 칸입니다. 본문과는 구분선으로 나뉩니다.
- 배경 이미지의 PC·모바일 높이 설정이 미리보기와 생성 CSS 양쪽에 적용됩니다. 배경은 선택기 자체 높이를 바꾸지 않고, 설정한 높이만큼 위에서부터 그려집니다. 선택기 나머지 영역에는 기본 배경색이 보입니다.

## 선택기 최대 너비

- 디자인 탭의 **선택기 최대 가로 너비**에서 280~1600px 사이로 지정합니다. 기본값은 760px입니다.
- 채팅 영역이 설정보다 넓으면 선택기는 지정한 너비에서 멈추고 가운데에 배치됩니다. 채팅 영역이 더 좁으면 화면 폭에 맞춰 자동으로 줄어듭니다.
- 설정값은 자동 저장, 프로젝트 JSON, 내 기본 디자인, 생성된 표시 정규식에 모두 포함됩니다.

## 이미지와 리수 에셋 연결

- **이미지 탭**에서 선택기 상단 이미지와 배경 이미지를 설정합니다. PC·모바일 높이, 영역 채우기/전체 보이기, 위·가운데·아래 초점과 배경 진하기를 조절할 수 있습니다.
- 관계 또는 퍼메를 선택한 **내용 탭**에서 해당 버튼의 썸네일을 설정합니다.
- `이미지 골라 미리보기`로 고른 로컬 파일은 현재 브라우저 탭의 미리보기에만 사용합니다. 이미지 데이터는 프로젝트 JSON이나 생성 코드에 넣지 않으므로 새로고침하면 다시 골라야 합니다.
- `리수 추가 에셋 이름`은 프로젝트와 자동 저장에 보존됩니다. 리수 캐릭터의 **추가 에셋**에 이미지를 등록하고 이름을 정확히 같게 지정하세요. 생성된 표시 정규식은 `{{raw::에셋 이름}}` 경로로 연결합니다.
- 상단·배경·썸네일을 사용하지 않을 때는 해당 에셋 이름을 비워 두면 됩니다. 이미지 파일을 바꾸되 이름을 유지하면 생성 코드를 다시 만들 필요가 없습니다.
- 브라우저 미리보기와 리수의 실제 크기는 채팅창 폭과 테마에 따라 조금 다를 수 있습니다. 생성 코드는 같은 맞춤·초점·높이 및 600px 이하 모바일 설정을 사용합니다.

## 모바일 설정과 디자인 저장

- 디자인 탭에서 PC 버튼 열 수와 모바일 버튼 열 수를 각각 1~8로 지정합니다. 모바일 기본값은 2열입니다. 모바일 글자 크기와 안쪽 여백도 별도로 설정합니다.
- 생성된 정규식은 화면 너비 600px 이하에서 모바일 설정을 적용합니다. 편집기의 모바일 보기 버튼은 PC에서도 모바일 설정을 확인할 수 있게 합니다.
- 현재 프로젝트의 설정과 테마는 브라우저에 자동 저장되고, 프로젝트 JSON에도 포함됩니다. 미리보기의 PC/모바일 모드도 같은 브라우저에서 기억합니다.
- **내 기본 디자인 저장**은 현재 색상·PC/모바일 배치·정렬 등을 브라우저에 보관합니다. 다른 프로젝트에서 **내 기본 디자인 적용**을 누르면 내용은 유지하며 디자인만 적용합니다. 다른 브라우저나 기기로 옮길 때는 프로젝트 JSON을 저장해 사용하세요.
- 테마 변경은 색상만 바꿉니다. 설정한 열 수·글자 크기·여백·둥글기·정렬은 유지합니다. 선택된 테마가 버튼에 표시되고, 색상을 직접 바꾸면 사용자 색상으로 취급합니다.
- `mobile-test.html`에서 모바일 CSS, 기본 디자인 저장/적용, 실제 새로고침 후 설정·테마 복원을 확인했습니다. 기존 14개 검사도 통과했습니다. 실제 리수 앱에서의 검증은 별도입니다.

**`퍼메 스튜디오.html`을 Edge 또는 Chrome으로 열면 바로 사용할 수 있습니다.** 이 파일 하나만 따로 복사해도 됩니다. 설치·서버·인터넷 연결은 필요하지 않습니다.

소스를 수정할 때는 `index.html`, `app.js`, `style.css`를 사용합니다. `index.html`도 직접 열 수 있습니다. 수정 뒤 `build.ps1`을 실행하면 단일 HTML에 반영됩니다.

## 편집과 저장

1. 관계를 선택하고 이름·설명을 편집합니다. `＋ 관계`로 추가합니다.
2. 관계 아래 `＋ 퍼메 추가`를 누르고 제목과 본문을 입력합니다. 복제·삭제·위아래 이동을 지원합니다.
3. 디자인 탭에서 색상, 버튼 열 수, 둥글기, 여백, 언어 버튼과 초기화 버튼을 설정합니다. **제목·안내문 / 버튼 묶음 / 버튼 안 글자**는 각각 왼쪽·가운데·오른쪽 정렬을 선택할 수 있습니다. 버튼 묶음 정렬은 접기 버튼, 언어 버튼, 초기화 버튼에도 적용되며 마지막 줄의 빈 공간 배치도 바뀝니다.
4. 미리보기에서 관계 → 퍼메를 눌러 선택 흐름을 확인합니다. **관계·퍼메·언어 버튼을 같은 묶음의 다른 버튼 앞이나 뒤로 드래그**하면 순서가 바뀝니다. 노란 선으로 삽입 위치를 확인하고 놓으세요. Esc 또는 묶음 밖에 놓으면 취소됩니다. 퍼메의 소속 관계를 옮기거나 픽셀 좌표로 자유 배치하는 방식은 아닙니다. 왼쪽 편집 목록의 위·아래 버튼도 계속 사용할 수 있습니다.
5. **프로젝트 저장**으로 JSON 파일을 내려받습니다. **불러오기**로 다시 열어 수정합니다. 다른 캐릭터로 재사용하려면 프로젝트를 불러온 다음 이름과 변수 접두사를 바꾸고 다른 파일명으로 저장하세요.

브라우저 자동 저장도 제공하지만 브라우저 설정·파일 위치·저장 용량에 따라 사용할 수 없거나 사라질 수 있습니다. 프로젝트 JSON을 기준 백업으로 사용하세요. 잘못된 파일을 불러오면 현재 프로젝트를 유지합니다.

v0.1 프로젝트도 불러올 수 있습니다. 정렬 항목이 없는 프로젝트에는 기존 배치를 유지하는 기본값을 채웁니다. 정렬과 드래그 순서는 프로젝트 JSON과 생성 정규식에 함께 반영됩니다. 테마를 바꿔도 정렬과 순서는 유지됩니다.

## 리수 적용

내보내기 탭에서 항목별로 복사하거나 파일로 저장합니다. 전체 코드 묶음은 사람이 읽고 각 설정에 나누어 붙이는 텍스트이며, 리수 모듈 파일이 아닙니다.

1. **첫 메시지 전체** → 캐릭터의 첫 메시지. 기존 첫 메시지를 보관한 뒤 교체하세요.
2. **Lua** → Lua 트리거 스크립트. 기존 스크립트가 있다면 함께 넣되, 같은 접두사의 이전 생성 함수는 교체합니다. `onInput`·`onOutput`·`onButtonClick`을 새로 선언하지 않습니다.
3. **표시 정규식 IN / OUT** → 새 정규식의 디스플레이 수정(`editdisplay`), custom flag 활성화, flag `g`.
4. **리퀘스트 정규식 IN / OUT** → 새 정규식의 리퀘스트 데이터 수정(`editprocess`), custom flag 활성화, flag `g`, OUT은 빈칸.
5. 새 채팅에서 관계와 퍼메를 선택합니다. AI에게 첫 응답을 요청하기 전에 프롬프트 보기에서 선택한 본문이 들어가는지 확인합니다.

본문은 디스플레이 정규식에만 넣지 않고 첫 메시지의 CBS 조건문에 넣었습니다. 그래야 화면뿐 아니라 프롬프트에도 선택한 본문이 반영됩니다. 미선택 상태에서는 본문이 비어 있으므로 관계와 퍼메를 먼저 선택하세요. 채팅 도중 선택을 바꾸면 첫 메시지의 조건부 본문도 바뀝니다. 시작 전 선택용으로 사용하세요.

본문의 CBS·마크다운은 그대로 보존합니다. 잘못 닫힌 CBS 구문이나 호출 문구와 같은 문자열을 본문에 직접 넣으면 의도와 다른 결과가 생길 수 있습니다. 제목·관계 이름 등 UI 라벨은 HTML/CBS 실행을 피하도록 텍스트로 처리합니다. 영어 본문이 비어 있으면 기본 본문을 사용합니다.

프로젝트를 수정한 뒤에는 **첫 메시지, Lua, 두 정규식**을 함께 갱신하고 새 채팅에서 확인하세요. 다른 선택기를 같이 사용할 때에는 변수 접두사와 호출 문구를 모두 다르게 지정하세요.

## 첫 버전의 범위

- 기본 예시는 야니크의 관계 구성을 참고해 새로 작성한 짧은 데모입니다. 첨부 카드의 원문 전체를 가져온 것이 아닙니다.
- 스튜디오 프로젝트 JSON의 저장·불러오기를 지원합니다. 임의의 카드 JPEG/PNG, 기존 Lua·정규식 역변환, 리수 카드 직접 수정은 지원하지 않습니다.
- 관계 선택은 이 프로젝트 접두사의 변수를 설정합니다. 기존 카드의 `jannikRelationship` 등과 로어북 조건을 자동 연결하지 않습니다.
- 버튼은 관계/퍼메 선택, 언어 전환, 접기/펼치기, 초기화를 지원합니다. 임의 Lua 동작을 만드는 편집기는 아닙니다.
- 미리보기는 브라우저에서 선택 흐름과 CSS를 보여 줍니다. 리수의 HTML 필터·CBS·마크다운·테마는 실제 리수에서 확인해야 합니다.
- 실제 리수 앱에 가져와 동작시키는 검증은 아직 하지 않았습니다.
